How to use

1. Set source impedance, line impedance and line delay.
2. Select an open, short or matched load.
3. Play the simulation to observe the travelling wave and reflections.
4. Switch between voltage/impedance and time/distance views.

Circuit Parameters

Propagation velocity as a fraction of light speed.

Use a very large value to approximate an open circuit.

Reflection Calculations

Initial voltage Vinitial —
E × Z0 / (Zs + Z0)
Load reflection coefficient ΓL —
(ZL − Z0) / (ZL + Z0)
Reflected voltage —
ΓL × Vinitial
Return loss —
−20 log10 |ΓL|

Understanding the Results

An open circuit reflects the incident voltage wave in phase.
